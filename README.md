# STRING THEORY - Album Listening Statistics

Динамический визуальный инструмент для анализа статистики прослушиваний альбома **STRING THEORY**.

## 📊 Просмотр статистики

### Вариант 1: Локальный запуск
Откройте файл `index.html` в любом браузере:
- Просто дважды кликните по файлу `index.html` в проводнике
- Или перетащите файл в окно браузера

### Вариант 2: GitHub Pages (если репозиторий опубликован)
👉 **[Открыть статистику онлайн](https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/)**

*(Замените `YOUR_USERNAME` и `YOUR_REPO_NAME` на ваши данные)*

## 📈 Возможности

- Интерактивные графики динамики прослушиваний по месяцам
- Распределение прослушиваний по трекам
- Сравнительная статистика между треками
- Карточки с общей статистикой альбома
- Сортировка и фильтрация данных
- Адаптивный дизайн для всех устройств

## 🎵 Треки альбома

Альбом включает 16 треков с общей статистикой более 2,200 прослушиваний за период с июня по декабрь 2021 года.

## 🚀 Использование

Просто откройте файл `index.html` в любом современном браузере для просмотра интерактивной статистики.
